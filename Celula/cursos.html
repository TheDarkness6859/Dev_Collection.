Manejo de plataforma digitales

Objetivo

Brindar a los participantes las competencias necesarias para utilizar de manera eficiente las principales plataformas digitales empleadas en entornos académicos, laborales y personales. Al finalizar el curso, el estudiante será capaz de navegar, gestionar información, comunicarse, colaborar en línea y aplicar buenas prácticas de seguridad digital dentro de diferentes herramientas y servicios digitales

Contenido Detallado del Curso

  • Módulo 1. Introducción al entorno digital
    1. Conceptos básicos de informática
    2. ¿Qué es una plataforma digital? Tipos y usos
    3. Equipos y navegadores: funciones esenciales
    4. Uso seguro y responsable de la tecnología

  • Módulo 2. Navegación en internet
    1. Motores de búsqueda (Google, Bing)
    2. Cómo realizar búsquedas eficientes
    3. Descarga y gestión de archivos
    4. Buenas prácticas de navegación segura

  • Módulo 3. Comunicación digital
    1. Correo electrónico (Gmail, Outlook): creación y gestión
    2. Chat y mensajería instantánea (WhatsApp Web, Telegram)
    3. Videollamadas y reuniones virtuales (Zoom, Meet)
    4. Etiqueta digital (Netiqueta)

  • Módulo 4. Plataformas de productividad
    1. Google Workspace (Drive, Docs, Sheets, Forms)
    2. Microsoft 365 (Word, Excel, PowerPoint)
    3. Organización personal: calendarios, recordatorios y notas
    4. Trabajo colaborativo en línea

  • Módulo 5. Plataformas de gestión y aprendizaje
    1. Bancos virtuales y transacciones digitales
    2. Plataformas de e-learning (Classroom, Moodle)
    3. Aplicaciones para trámites ciudadanos (gobierno digital)
    4. Creación y gestión de cuentas de usuario

  • Módulo 6. Redes sociales y comunidades digitales
    1. Uso responsable de las redes sociales
    2. Facebook, Instagram, TikTok: funciones esenciales
    3. Creación de contenido básico
    4. Gestión de privacidad en redes sociales

  • Módulo 7. Seguridad digital
    1. Contraseñas y autenticación segura
    2. Identificación de fraudes y estafas digitales
    3. Copias de seguridad
    4. Cuidado de datos personales

  • Módulo 8. Proyecto final
    1. Integración de varias plataformas digitales
    2. Presentación de un trabajo utilizando herramientas del curso
    3. Evaluación de competencias adquiridas
